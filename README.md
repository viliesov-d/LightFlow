# LightFlow

Безкоштовний проєкт онлайн-графіка відключень електроенергії для Черкаської області (черга 1.1).

Мета: два віджети для Android та iPhone — маленький із плановим статусом і великий зі статусом та добовим графіком.

Архітектура: офіційні публікації Черкасиобленерго → серверний парсер → майбутній JSON API → Android / iOS Scriptable.

> Проєкт у розробці. «Світло є/немає» — лише статус **за графіком**, а не факт фізичної наявності електропостачання.
