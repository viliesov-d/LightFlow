# LightFlow ⚡

Безкоштовні онлайн-віджети графіка відключень електроенергії. Перший регіон: **Черкаська область, черга 1.1**.

- **Маленький віджет:** чи має бути світло за графіком.
- **Великий віджет:** статус за графіком і часові інтервали відключень.
- **Платформи:** Android (нативний APK), iPhone (Scriptable).
- **Принцип:** тільки онлайн, без локального збереження графіків у застосунку.

> ⚠️ Статус **за графіком** не підтверджує фактичної наявності електроенергії. Офіційне джерело: [АТ «Черкасиобленерго»](https://www.cherkasyoblenergo.com/media).

## Етап A1 — адаптер офіційних публікацій

`src/cherkasy.mjs` — модуль Node.js / Cloudflare Workers без сторонніх залежностей. Уміє:

1. Розпізнавати повідомлення про графіки ГПВ у медіацентрі.
2. Визначати дату графіка, враховуючи рік та перехід грудень → січень.
3. Знаходити останнє оновлення для заданого дня за часом публікації.
4. Читати інтервали черги 1.1, включаючи півгодинні та `24:00`.
5. Відхиляти некоректні, відсутні або перехресні інтервали.
6. Повертати `null`, якщо графік на дату ще не опубліковано (це **не** означає, що світло гарантовано є).

```js
import { fetchLatestSchedule } from './src/cherkasy.mjs';

const schedule = await fetchLatestSchedule({ date: '2026-11-10' });
console.log(schedule);
// { region, queue, date, timezone, publishedAtLocal, sourceUrl, outages }
```

### Тестування

Потрібен Node.js 20+.

```bash
npm test
```

Тести побудовані на HTML-фікстурах, що імітують офіційні публікації від 9 листопада 2026 (початкова 20:58, оновлення 23:06). Вони **не** є інтеграційним тестом доступу до живого сайту: перед запуском сервера потрібно перевірити фактичну HTML-розмітку, доступ з Cloudflare та умови автоматичного читання джерела.

### Обмеження етапу A1

- Поки обробляємо тільки опубліковані текстові графіки ГПВ. Необхідно додати обробку повідомлень про скасування графіка або публікацій у новому форматі.
- Модуль читає першу сторінку медіацентру. Далі буде розширення пошуку, якщо потрібної дати немає серед останніх повідомлень.
- Сервер/API, Cloudflare, сайт та віджети **ще не розгорнуті**.
- Ніяких платних сервісів або ключів у репозиторії не використовуємо.

## Наступні етапи

A2 — надійний збір актуальних публікацій і Cloudflare Worker із JSON API; B — онлайн-сайт; C — Android та iPhone віджети; D — перевірка оновлень у реальних умовах.

Проєкт не є офіційним сервісом Черкасиобленерго.
