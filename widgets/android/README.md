# LightFlow 0.4.0 — три Android-віджети

Android 8.0+ · безкоштовно · без локальної бази графіків · джерело через Cloudflare API.

## Обраний дизайн 0.4.0

Реалізовано стиль **Soft Minimal**, погоджений за зображенням із трьома віджетами.

- **Малий:** чистий симетричний контур лампочки теплого золотистого кольору під час планової наявності світла, коралового — під час планового відключення, сірого — якщо даних немає. Жовта блискавка; внизу **лише години**.
- **Горизонтальний:** зверху зліва невелика крапка та напис «Є світло» / «Відключення». Нижче — м'які капсули зі світлими градієнтами; кожна займає **66% ширини**, усередині **тільки часовий інтервал**. Активний інтервал підсвічено; сусідні видно частково, карусель поступово зсувається за часом телефона. Маленька стрілка **завжди по центру**.
- **Великий:** чистий круговий графік з усіма 24 годинами та точними офіційними інтервалами; часова стрілка стала короткою, з білою точкою на кільці; центр з датою, підчергою 1.1 і статусом не перекритий.
- **Єдині кольори:** темний синьо-графітовий фон з ледве помітним градієнтом, світлий м'ятний, кораловий, кремово-золотистий для лампочки й світлий текст.
- **Оновлення:** натискання на будь-який віджет, як і раніше, не відкриває сайт. **8 кадрів** хвиль з інтервалом приблизно 105 мс. Контейнер та overlay під час оновлення обрізаються за заокругленим контуром, щоб не виникали гострі кути.

**Логіка та джерело графіків незмінні.** Це тільки оновлення оформлення. Рух каруселі та стрілки на кільці розраховується за системним часом під час кожного перемалювання; Android може відкладати такі оновлення, тому плавний рух щосекунди неможливо гарантувати.

## Дизайн

**1. Лампочка (малий, 2×2)**

- Лише лампочка й точний інтервал поточного періоду під нею, наприклад 08:00–10:00.
- Тепло-золотиста лампочка означає період **зі світлом за графіком**, коралова — **планове відключення**, сіра — немає перевіреного графіка.
- Жодних інших підписів, дат та кнопок.

**2. Карусель (горизонтальний, приблизно 4×2)**

- Кожен блок має **66% ширини видимого графіка**.
- **Лише час** міститься всередині великих блоків; статус винесено над ними зліва. Сусідні блоки частково видно з боків.
- **Нерухома стрілка по центру знизу**, графік зсувається відносно неї залежно від пройденої частини поточного часового інтервалу.
- Зсув розраховується за київським часом телефона на кожному перемалюванні. Це не фізичне плавне 60 FPS-прокручування, адже стандартний Android-віджет не підтримує постійну анімацію.

**3. Круговий годинник (великий, 4×4)**

- Кільце з **24 годинами**; зелений/червоний сектор відображає інтервал, отриманий від API, з точністю до хвилини.
- Дата, черга 1.1 та статус **за графіком** по центру.
- Стрілка обчислюється за **годинами, хвилинами й секундами системного часу** під час перемалювання.
- Android може затримувати фонові оновлення; між ними стрілка залишається в положенні останнього перемалювання. Постійне плавне обертання в стандартному RemoteViews не гарантується.

## Оновлення

- Сервер перевіряє джерело раз на **4 хвилини**.
- Звичайний WorkManager — приблизно раз на **15 хвилин**.
- Додатковий **необов'язковий за точністю** системний AlarmManager просить перемалювання приблизно раз на 5 хвилин, без дозволів на точні будильники.
- Окрема перевірка запланована поблизу межі наступного ввімкнення/вимкнення за графіком.
- Натискання будь-якого віджета запускає ефект хвиль та онлайн-оновлення. **Сайт не відкривається.**
- Якщо даних немає, замість припущення про наявність світла відображається сірий/невідомий стан.

> У режимі енергозбереження Android або оболонка телефона можуть затримувати оновлення: анімацію, рух каруселі та позицію стрілки неможливо гарантувати кожну хвилину без постійно активного застосунку. Самі інтервали беруться із перевіреного API — дані не зберігаються у файлах телефона.

## Як установити

1. Відкрий [GitHub Actions — Android APK](https://github.com/viliesov-d/LightFlow/actions/workflows/android-apk.yml).
2. Вибери **успішну збірку останньої версії** з основної гілки main.
3. У розділі **Artifacts** завантаж LightFlow-Android-debug-APK.
4. Розпакуй ZIP та встанови app-debug.apk.
5. На головному екрані утримай порожнє місце → **Віджети** → **LightFlow** → вибери потрібний із трьох.

**Важливо для тестових APK:** якщо нова збірка не встановлюється поверх старої через інший debug-підпис, видали попередні віджети та застосунок LightFlow і встанови новий APK заново. Локальної історії графіків немає, тож нічого не втратиш.

## Збірка вручну

Відкрий папку widgets/android/ у Android Studio з JDK 17 та Android SDK 36. Команда: gradle assembleDebug. Файл: app/build/outputs/apk/debug/app-debug.apk.

## Відомі обмеження

- Швидкість фонових запусків визначає Android.
- Системний віджет не передає точні координати дотику — хвилі йдуть від центру.
- Віджети показують **планові** відключення, а не фактичну наявність електроенергії.
- На iPhone поки залишено окремі Scriptable-віджети; ця Android-версія не змінює їхній код.
