# LightFlow — Android-віджети

Два справжні віджети головного екрана:
- **маленький (2×2)** — статус за опублікованим графіком, найближча зміна;
- **великий (4×4)** — статус і згруповані інтервали 00:00–24:00.

Android 8.0+ (minSdk 26). Завантажує дані через HTTPS з LightFlow API, без локальної бази графіків, облікового запису та платних підписок.

## Нове у версії 0.2.0 — натискання на віджет

- Торкання **будь-якої частини маленького чи великого віджета** більше не відкриває сайт.
- Поверх усього віджета з'являється напівпрозорий шар із хвилями м'ятного кольору, що розходяться від центру: 4 послідовні векторні кадри.
- Після хвиль поступово з'являються написи **«Оновлюємо…»**, **«Оновлюємо графік…»**, **«Перевіряємо дані…»**.
- Запускається окремий онлайн-запит через WorkManager; після його завершення знову відображається актуальний графік або **«Статус невідомий»**, якщо API не підтверджує дані.
- Для Android 12+ користувацький запит позначається як expedited, із безпечним поверненням до звичайного режиму в разі вичерпання квоти.

**Особливість Android:** класичний віджет `RemoteViews` не передає точні координати торкання й не дозволяє виконувати довільні безперервні анімації. Тому хвилі йдуть **від центру віджета**, а ефект реалізовано покадрово через системні оновлення; швидкість/плавність залежать від оболонки телефона. Це не анімація 60 FPS і не відкриття окремого екрана.

**Додаткове прискорення:** сервер отримує оновлення джерела кожні **4 хвилини**; Android зберігає 15-хвилинний періодичний запуск та окремо планує одноразову перевірку поблизу найближчої межі інтервалу зі світлом / без світла. WorkManager не гарантує точний запуск у задану секунду. Дані на телефоні не кешуються.



## Збірка

Підтримується Android Studio або CI GitHub Actions.

1. Відкрий у Android Studio папку `widgets/android/`.
2. Вибери `Build > Build APK(s)`, або виконай `gradle assembleDebug` із Gradle 9.1+ та JDK 17.
3. APK буде в `app/build/outputs/apk/debug/app-debug.apk`.
4. Встанови APK на телефон, дозволь установку з цього джерела.
5. Затисни порожнє місце на головному екрані → Віджети → **LightFlow** → вибери маленький або великий.

[GitHub Actions — збірки APK](https://github.com/viliesov-d/LightFlow/actions/workflows/android-apk.yml). Відкрий успішний запуск та завантаж артефакт `LightFlow-Android-debug-APK`.

## Якщо встановлено попередній APK

У першій версії був несумісний із Android RemoteViews елемент `<Space>`, через який домашній екран міг показувати **«Не вдалося завантажити віджет»**. Починаючи з версії `0.1.1` цей елемент замінено на підтримуваний `TextView`.

**Для тестової збірки з GitHub Actions потрібно спочатку видалити старі віджети й попередній застосунок LightFlow, а потім установити новий APK.** Debug APK, зібрані на різних раннерах, можуть мати різні підписи, через що пряме оновлення поверх старої версії не встановиться. Дані графіків локально не зберігаються, тож видалення застосунку їх не зітре.

Після встановлення додай віджети заново. Якщо проблема залишиться, збережи скриншот і за можливості журнал `adb logcat` із помилкою `RemoteViews` або `AppWidgetHostView`.

## Безпека та обмеження

- Звичайне фонове періодичне оновлення відбувається приблизно кожні 15 хв, додатково можливі перевірки на межах інтервалів та після натискання. Android може затримувати фонові запуски.
- Якщо API або інтернет недоступні під час оновлення, віджет змінить стан на **Статус невідомий**.
- Система Android може зберігати попереднє відображення віджета до виконання наступної фонової задачі. Це не локальна база графіків LightFlow.
- Через обмежені розміри великого віджета показано до 10 згрупованих інтервалів. Якщо інтервалів більше, останній рядок показує кількість непоказаних; повний графік доступний на окремому сайті.
- Натискання на віджет запускає анімоване ручне оновлення без відкриття сайту. Натискання на іконку самого застосунку, як і раніше, відкриває сайт.
- Віджет відображає **плановий** графік, а не фізичну наявність електроенергії.

## Статус

Проєкт містить джерельний код. Перевірка збірки APK виконується в CI; встановлення на реальному Android потребує тестування.
