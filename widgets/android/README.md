# LightFlow — Android-віджети

Два справжні віджети головного екрана:
- **маленький (2×2)** — статус за опублікованим графіком, найближча зміна;
- **великий (4×4)** — статус і згруповані інтервали 00:00–24:00.

Android 8.0+ (minSdk 26). Завантажує дані через HTTPS з LightFlow API, без локальної бази графіків, облікового запису та платних підписок.

## Збірка

Підтримується Android Studio або CI GitHub Actions.

1. Відкрий у Android Studio папку `widgets/android/`.
2. Вибери `Build > Build APK(s)`, або виконай `gradle assembleDebug` із Gradle 9.1+ та JDK 17.
3. APK буде в `app/build/outputs/apk/debug/app-debug.apk`.
4. Встанови APK на телефон, дозволь установку з цього джерела.
5. Затисни порожнє місце на головному екрані → Віджети → **LightFlow** → вибери маленький або великий.

[GitHub Actions — збірки APK](https://github.com/viliesov-d/LightFlow/actions/workflows/android-apk.yml). Відкрий успішний запуск та завантаж артефакт `LightFlow-Android-debug-APK`.

## Якщо встановлено попередній APK

У першій версії був несумісний із Android RemoteViews елемент `<Space>`, через який домашній екран міг показувати **«Не вдалося завантажити віджет»**. У версії `0.1.1` цей елемент замінено на підтримуваний `TextView`.

**Для тестової збірки з GitHub Actions потрібно спочатку видалити старі віджети й попередній застосунок LightFlow, а потім установити новий APK.** Debug APK, зібрані на різних раннерах, можуть мати різні підписи, через що пряме оновлення поверх старої версії не встановиться. Дані графіків локально не зберігаються, тож видалення застосунку їх не зітре.

Після встановлення додай віджети заново. Якщо проблема залишиться, збережи скриншот і за можливості журнал `adb logcat` із помилкою `RemoteViews` або `AppWidgetHostView`.

## Безпека та обмеження

- WorkManager запитує API не частіше ніж приблизно кожні 15 хв. Android сам визначає точний час фонових запусків, тому можливі затримки.
- Якщо API або інтернет недоступні під час оновлення, віджет змінить стан на **Статус невідомий**.
- Система Android може зберігати попереднє відображення віджета до виконання наступної фонової задачі. Це не локальна база графіків LightFlow.
- Через обмежені розміри великого віджета показано до 10 згрупованих інтервалів. Якщо більше, останній рядок веде до сайту, де показано всі інтервали.
- Натискання на будь-який віджет відкриває онлайн-сайт LightFlow.
- Віджет відображає **плановий** графік, а не фізичну наявність електроенергії.

## Статус

Проєкт містить джерельний код. Перевірка збірки APK виконується в CI; встановлення на реальному Android потребує тестування.
