# LightFlow на iPhone — безкоштовно й без поновлення підпису

Це **не IPA**, і це навмисно. Застосунок LightFlow встановлюється через Safari і відкривається з іконки на домашньому екрані окремим вікном, а чотири iOS-віджети працюють через безкоштовний Scriptable з App Store. **Жодного Apple Developer Account, Mac, AltStore чи 7-денного перепідписування немає.**

- **Лампочка — малий (Small):** золота / коралова лампочка і поточний інтервал.
- **Міні-графік — малий (Small):** 24 кольорові сектори, 8 позначок годин, дата, черга 1.1 і стан.
- **Великий круговий графік — великий (Large):** 24 години, дата, підчерга 1.1, статус і біла стрілка часу.

- **Екран блокування — прямокутний (Rectangular):** контрастна лампочка, підчерга 1.1, текстовий стан та поточний інтервал.

Всі чотири — **один файл** [LightFlow.js](LightFlow.js), з трьома домашніми режимами та режимом `lock`.

## Системний Liquid Glass / Clear (iOS 26+)

У цій версії LightFlow **не малює власне скло**. Скрипт створює лише лампочку, графік, текст і стрілку на прозорому полотні. Він задає `Color.clear()` для контейнера Scriptable і зберігає Retina-чіткість (`DrawContext.respectScreenScale = true`). Немає ні псевдопрозорої картинки шпалер, ні намальованих рамок чи блюру.

**Як перевірити справжнє системне скло на iPhone:**

1. Відкрий Scriptable → `LightFlow`, повністю заміни старий код свіжим [LightFlow.js](LightFlow.js) і збережи.
2. На початковому екрані затисни порожнє місце, вибери **Редагувати → Налаштувати → Прозорі / Clear** (назви можуть відрізнятися за версією iOS). Можна вибрати світлий, темний або автоматичний режим Clear.
3. Перевір **вже додані** три Scriptable-віджети (`bulb`, `mini`, `large`) без зміни параметрів. У самому Scriptable перегляд може відрізнятися від вигляду на початковому екрані.
4. Якщо зображення старе, зайди в редагування віджета, перевір `Script: LightFlow`, закрий редагування та дай iOS перерисувати його.

**Обмеження:** режим Clear застосовується до оформлення початкового екрана загалом, а не окремо до LightFlow. **Тільки iOS може намалювати справжній Liquid Glass.** Прозорий Scriptable-контент не гарантує, що його контейнер отримає точно такий самий ефект, як системний «Годинник». Крім того, iOS у прозорому режимі може змінювати кольори зображення віджета: якщо м'ятний і кораловий зіллються, звіряй стан за текстом. Якщо система залишить звичайний фон, JavaScript не має підтримуваного способу примусово активувати нативний WidgetKit-матеріал — для повного контролю потрібен власний застосунок WidgetKit.

**Жодного нового встановлення чи підпису не потрібно.** API, дані, оновлення, підчерга та три домашні параметри віджетів залишилися як були.

## 1. Додай застосунок LightFlow на головний екран iPhone

1. Відкрий **Safari** на iPhone.
2. Перейди на [LightFlow](https://lightflow-api.lightflow-viliesov.workers.dev/).
3. Натисни **Поділитися** (залежно від iOS: спочатку меню сторінки), потім **На Початковий екран / Add to Home Screen**.
4. Переконайся, що **«Відкривати як вебзастосунок / Open as Web App»** увімкнено (якщо перемикач доступний).
5. Натисни **Додати**.

На екрані з’явиться **LightFlow з нашою іконкою**. Він працює як окреме вікно без вкладок Safari, але **тільки онлайн**. Сайт сам по собі не надає нативних iOS-віджетів.

## 2. Установи Scriptable та один код

1. Установи безкоштовний [Scriptable в App Store](https://apps.apple.com/app/scriptable/id1405459188).
2. Відкрий [наш готовий скрипт LightFlow.js](https://github.com/viliesov-d/LightFlow/blob/main/widgets/ios/LightFlow.js). У GitHub відкрий **Raw**, скопіюй увесь JavaScript-код.
3. Відкрий Scriptable → **+** → створи скрипт. Назви його точно **LightFlow**.
4. Встав код і збережи.
5. Запусти один раз у Scriptable, щоб перевірити інтернет. Побачиш попередній перегляд лампочки.

## 3. Додай три віджети на початковий екран

На головному екрані iPhone затисни вільне місце → **+ / Додати віджет** → знайди **Scriptable**.

| Який віджет | Розмір Scriptable | Script | Parameter |
|---|---|---|---|
| Лампочка | **Small** | LightFlow | **bulb** |
| Міні-графік | **Small** | LightFlow | **mini** |
| Великий круговий графік | **Large** | LightFlow | **large** |

Для кожного: додай віджет потрібного розміру → **затисни його → Редагувати віджет / Edit Widget** → у полі **Script** вибери LightFlow, а в полі **Parameter** введи слово з таблиці **без лапок**. Можна додавати кілька Scriptable-віджетів з одним скриптом.

У Scriptable під час ручного запуску без параметра показується лампочка. На домашньому екрані великий віджет автоматично показує великий круговий графік.

## 4. Додай четвертий віджет на екран блокування

1. Онови наявний скрипт LightFlow до свіжого [LightFlow.js](LightFlow.js), не створюючи нового скрипта.
2. Затисни екран блокування → **Налаштувати → Екран блокування**.
3. Натисни область віджетів під годинником → **Scriptable** → вибери широкий прямокутний віджет (Rectangular, 1×2).
4. Натисни доданий віджет, вибери **Script: LightFlow**, у **Parameter** введи **lock** (без лапок, якщо поле доступне). Скрипт також автоматично розпізнає прямокутний формат, тому параметр необов'язковий.
5. Натисни **Готово**. Наявні домашні віджети видаляти чи переналаштовувати не потрібно.

Віджет підтримує світло, відключення та відсутність перевірених даних. Фон прозорий, колір оформлення визначає iOS; стан завжди написано словами. Інтервал відображається за київським часом. Це плановий, не фактичний стан електромережі. Реальний вигляд може відрізнятися від перегляду в Scriptable.

## Як оновлюються графіки

- Scriptable кожного запуску читає [наш Cloudflare API](https://lightflow-api.lightflow-viliesov.workers.dev/api/v1/schedule); локальної бази/файлового кешу графіків немає.
- Для перевірки потрібні: підчерга **1.1**, сьогоднішня дата в Києві, покриття 00:00–24:00, перевірка не старша 20 хвилин. Невірні та застарілі дані **не показуються як актуальні**.
- Віджет запитує наступне оновлення через **15 хвилин**, але iOS самостійно вирішує, коли воно фактично відбудеться. Не можна гарантувати ні 15 хвилин, ні рух стрілки щосекунди.
- Стрілка береться з системного часу **в момент малювання**, а не з даних сервера.
- Скрипт не задає `widget.url`, щоб не перекривати системне налаштування дії натискання Scriptable. Якщо у меню редагування віджета доступний **When Interacting → Open URL**, можна вказати адресу `https://lightflow-api.lightflow-viliesov.workers.dev/`. Наявність цього пункту залежить від версії Scriptable та iOS. Відкриття саме встановленого вебзастосунку, а не браузера, не гарантоване. Android-логіка «одне натискання оновлює, подвійне відкриває» на звичайних iOS Scriptable-віджетах **не підтримується**.
- Рисунок намагається бути прозорим, але iOS може накладати системну підкладку залежно від версії ОС та оформлення.
- iOS може тимчасово залишати на екрані **попереднє зображення** віджета після втрати інтернету до наступного запуску скрипта. Це системна поведінка, а LightFlow не зберігає локальну історію.

**Важливо:** це графік **планових** відключень, не вимірювання фактичної наявності електроенергії.

## Перевірка

В GitHub Actions автоматично перевіряються синтаксис, чотири режими, прямокутний віджет блокування, малювання секторів, дата Europe/Kyiv і відсутність неактуальних даних. Справжній вигляд і регулярність оновлень на iPhone потрібно перевірити вручну.
