# LightFlow на iPhone — безкоштовно й без поновлення підпису

Це **не IPA**, і це навмисно. Застосунок LightFlow відкривається з іконки на домашньому екрані через Safari, а три iOS-віджети працюють через безкоштовний Scriptable з App Store. **Жодного Apple Developer Account, Mac, AltStore чи 7-денного перепідписування немає.**

- **Лампочка — малий (Small):** золота / коралова лампочка і поточний інтервал.
- **Міні-графік — малий (Small):** 24 кольорові сектори, 8 позначок годин, дата, черга 1.1 і стан.
- **Великий круговий графік — великий (Large):** 24 години, дата, підчерга 1.1, статус і біла стрілка часу.

Всі три — **один файл** [LightFlow.js](LightFlow.js) та три віджети з різними параметрами.

## Оформлення Soft Glass

Поточна версія має **легкий скляний стиль** у всіх трьох віджетах:

- Темно-синя напівпрозора підкладка з округлими краями, ледь помітним затемненням унизу.
- Тонка світла рамка, делікатний верхній відблиск і стримане підсвічування.
- Чіткіші контури лампочки, годинні цифри й білі покажчики; під текстом легка тінь.
- Увімкнено **Retina-рендеринг** через `DrawContext.respectScreenScale = true`, щоб iPhone не розтягував низькороздільне зображення.

**Це стилізація скла, а не живий blur шпалер.** Scriptable не має доступу до шпалер під віджетом. iOS також може застосувати власну непрозору підкладку чи відтінок залежно від теми та вигляду віджетів.

**Оновлення вже наявних віджетів:** у Scriptable відкрий скрипт `LightFlow`, заміни старий код новим [LightFlow.js](LightFlow.js) повністю та збережи. Параметри `bulb`, `mini`, `large` міняти не потрібно. Перевір вигляд у попередньому перегляді скрипта та на домашньому екрані.


## 1. Додай застосунок LightFlow на головний екран iPhone

1. Відкрий **Safari** на iPhone.
2. Перейди на [LightFlow](https://lightflow-api.lightflow-viliesov.workers.dev/).
3. Натисни **Поділитися** (залежно від iOS: спочатку меню сторінки), потім **На Початковий екран / Add to Home Screen**.
4. Переконайся, що **«Відкривати як вебзастосунок / Open as Web App»** увімкнено (якщо перемикач доступний).
5. Натисни **Додати**.

На екрані з’явиться **LightFlow з нашою іконкою**. Він працює як окреме вікно без вкладок Safari, але **тільки онлайн**. Сайт сам по собі не надає нативних iOS-віджетів.

## 2. Установи Scriptable та один код

1. Установи безкоштовний [Scriptable в App Store](https://apps.apple.com/app/scriptable/id1405459188).
2. Відкрий [наш готовий скрипт LightFlow.js](https://github.com/viliesov-d/LightFlow/blob/main/widgets/ios/LightFlow.js). У GitHub відкрий **Raw**, скопіюй увесь JavaScript-код.
3. Відкрий Scriptable → **+** → створи скрипт. Назви його точно **LightFlow**.
4. Встав код і збережи.
5. Запусти один раз у Scriptable, щоб перевірити інтернет. Побачиш попередній перегляд лампочки.

## 3. Додай всі три віджети

На головному екрані iPhone затисни вільне місце → **+ / Додати віджет** → знайди **Scriptable**.

| Який віджет | Розмір Scriptable | Script | Parameter |
|---|---|---|---|
| Лампочка | **Small** | LightFlow | **bulb** |
| Міні-графік | **Small** | LightFlow | **mini** |
| Великий круговий графік | **Large** | LightFlow | **large** |

Для кожного: додай віджет потрібного розміру → **затисни його → Редагувати віджет / Edit Widget** → у полі **Script** вибери LightFlow, а в полі **Parameter** введи слово з таблиці **без лапок**. Можна додавати кілька Scriptable-віджетів з одним скриптом.

У Scriptable під час ручного запуску без параметра показується лампочка. На домашньому екрані великий віджет автоматично показує великий круговий графік.

## Як оновлюються графіки

- Scriptable кожного запуску читає [наш Cloudflare API](https://lightflow-api.lightflow-viliesov.workers.dev/api/v1/schedule); локальної бази/файлового кешу графіків немає.
- Для перевірки потрібні: підчерга **1.1**, сьогоднішня дата в Києві, покриття 00:00–24:00, перевірка не старша 20 хвилин. Невірні та застарілі дані **не показуються як актуальні**.
- Віджет запитує наступне оновлення через **15 хвилин**, але iOS самостійно вирішує, коли воно фактично відбудеться. Не можна гарантувати ні 15 хвилин, ні рух стрілки щосекунди.
- Стрілка береться з системного часу **в момент малювання**, а не з даних сервера.
- При натисканні Scriptable-віджет **відкриває сайт LightFlow**. Android-логіка «одне натискання оновлює, подвійне відкриває» на звичайних iOS Scriptable-віджетах **не підтримується**.
- Рисунок намагається бути прозорим, але iOS може накладати системну підкладку залежно від версії ОС та оформлення.
- iOS може тимчасово залишати на екрані **попереднє зображення** віджета після втрати інтернету до наступного запуску скрипта. Це системна поведінка, а LightFlow не зберігає локальну історію.

**Важливо:** це графік **планових** відключень, не вимірювання фактичної наявності електроенергії.

## Перевірка

В GitHub Actions автоматично перевіряються синтаксис, три параметри, малювання секторів, дата Europe/Kyiv і відсутність неактуальних даних. Справжній вигляд і регулярність оновлень на iPhone потрібно перевірити вручну.
