# LightFlow на iPhone — два віджети через Scriptable

**Ні Mac, ні платний Apple Developer Account не потрібні.**

Один скрипт `LightFlow.js` підтримує два розміри:
- **Малий** — плановий статус і час найближчої зміни.
- **Великий** — статус і всі згруповані інтервали від 00:00 до 24:00.

## Як встановити

1. Встанови безкоштовний [Scriptable](https://apps.apple.com/app/scriptable/id1405459188) на iPhone.
2. Відкрий [LightFlow.js](https://github.com/viliesov-d/LightFlow/blob/main/widgets/ios/LightFlow.js) у GitHub, скопіюй **весь код** (Raw).
3. У Scriptable створи новий скрипт із назвою **LightFlow** та встав код.
4. На домашньому екрані iPhone затисни порожнє місце → додай віджет **Scriptable**.
5. Обери розмір **Small** або **Large**, торкнися віджета й вибери скрипт **LightFlow**.
6. Додай другий розмір таким самим способом — обидва використовують один скрипт.

## Принцип роботи

- Кожен запуск скрипта робить HTTPS-запит до `/api/v1/schedule`; локального збереження даних немає.
- Якщо API повертає застарілий або неперевірений графік, скрипт показує **Статус невідомий**.
- Перевіряються дата в Києві, час синхронізації (не старше 20 хв) та повне покриття 24 годин без прогалин.
- iOS сама визначає фактичну частоту оновлення. `refreshAfterDate` — лише прохання не раніше ніж через 15 хв; миттєву зміну у фоновому режимі гарантувати не можна.
- При втраті інтернету iOS може тимчасово зберігати попереднє **зображення віджета** до наступного виконання; ми не створюємо файловий кеш.
- Напис «Світло має бути» означає **за опублікованим графіком**, а не фізично підтверджену наявність.

## Перевірки

Синтаксис скрипта перевіряється в GitHub Actions, але перевірка відображення на реальному iPhone має бути зроблена вручну.
