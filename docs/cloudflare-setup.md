# LightFlow — безкоштовне розгортання Cloudflare Worker

> Це інструкція; **жоден Cloudflare Worker не буде запущений**, доки власник акаунта сам не налаштує Cloudflare.

## 1. Підготовка

1. Створи безкоштовний акаунт на https://dash.cloudflare.com/ .
2. На комп'ютері встанови Node.js 22+ та Git.
3. У PowerShell виконай:
   ```powershell
   git clone https://github.com/viliesov-d/LightFlow.git
   cd LightFlow
   npm install
   npx wrangler login
   ```
4. Створи KV namespace:
   ```powershell
   npx wrangler kv namespace create SCHEDULES
   ```
5. Скопіюй ID з відповіді в `wrangler.jsonc`, замінивши `REPLACE_WITH_YOUR_CLOUDFLARE_KV_NAMESPACE_ID`. **ID namespace — не секрет**, але секретні токени в GitHub не коміть.
6. Перевір тести і опублікуй Worker:
   ```powershell
   npm test
   npx wrangler deploy
   ```
7. Отримаєш URL виду `https://lightflow-api.<твоє-ім'я>.workers.dev`. Перевір:
   - `https://lightflow-api.<твій-домен>.workers.dev/health`
   - `https://lightflow-api.<твій-домен>.workers.dev/api/v1/schedule`
   - `https://lightflow-api.<твій-домен>.workers.dev/api/v1/schedule?date=2026-11-11` — якщо завтра 11 листопада 2026.

Спочатку API може повертати `kind:"unknown"` — це нормально до першого успішного Cron. Cloudflare Cron Triggers використовують UTC; `*/5 * * * *` запускає кожні 5 хв незалежно від часової зони. Дата графіка визначається за `Europe/Kyiv`.

## Безпека та точність

- API **лише читає KV**; публічний GET не звертається до Черкасиобленерго.
- Сервер перевіряє джерело **кожні 5 хвилин** для сьогодні та завтра, використовуючи один список новин за цикл.
- **Лише оновлені й перевірені дані** можуть змінити статус. Якщо джерело недоступне понад 20 хвилин, API повертає `unknown` і не стверджує, що світло є.
- Якщо з'явилася нова публікація, але її не вийшло перевірити, API одразу позначає її як неперевірену.
- Якщо графіка немає в недавніх публікаціях, API повертає невідомий стан, а не «світло є».
- У випадку зникнення електропостачання поза графіком сервер **не може виявити факт** без окремого надійного датчика або джерела.

## Ліміти безкоштовного тарифу

Workers Free: до 100 000 викликів/добу. KV Free: 100 000 читань та 1 000 записів за добу (перевірити актуальні умови в Cloudflare).

Cron робить **максимум 2 звичайні записи KV за 5 хв** ≈ 576 записів на добу. Коли знаходить нову версію для певної дати, додає один архівний запис. Тому базове використання вміщується у KV Free. Читання публічних API також витрачають квоту KV, тому для великої кількості користувачів може знадобитися оптимізація.

## Обмеження перед запуском

HTML-сайт Черкасиобленерго може змінювати формат або обмежувати автоматичні запити. Додаткова діагностика GitHub Actions 10.11.2026 успішно отримала **живу публікацію** та розпізнала 5 інтервалів черги 1.1. Це не гарантує, що запити з Cloudflare також доступні. Перевір доступ і умови автоматичного читання джерела перед ввімкненням Cron. Unit-тести використовують локальні HTML-фікстури.
